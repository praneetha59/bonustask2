MyToken – Features & Usage Guide
Features

Token Initialization
Set token name, symbol, total supply, and decimals during deployment.

Token Transfer
Transfer tokens between wallet addresses using transfer().

Allowance System
Approve another account to spend tokens using
approve() and transferFrom().

Event Emission
Emits Transfer and Approval events for transparency and tracking.

Balance Tracking
View account balances with balanceOf().

How to Deploy (Remix IDE)

Open Remix IDE

Create a new file → MyToken.sol

Paste the smart contract code

Select Solidity 0.8.x compiler → Compile

Go to Deploy & Run Transactions

Choose JavaScript VM (or Injected Provider)

Enter constructor parameters

Click Deploy
